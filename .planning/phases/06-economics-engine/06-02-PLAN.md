- B: removable per pool = F x r_eff if >= min_removable_fte else 0 (fragmented, reported); reviewers use E under the same threshold (INV-4); labour saving = removable x loaded; agency saving = sum agency x s_eff; one-off = build + change_cost_per_fte x marketing_fte (Q2: reviewers inside the 120) + severance (removable x loaded x severance_months / 12, Speculative, B only); net = labour + agency - run; year1 = year1_realisation x (labour + agency) - run (Q5: B only); payback simple = one_off / net; ramped = one_off / year1 if one_off <= year1 else 1 + (one_off - year1) / net; null when net <= 0.
- C: d = demand_multiplier, W8 demand = min(d, traffic_growth); per pool without = F x d (reviewers Req0 x d), with = F x d x (1 - r_eff) (reviewers ReqP1 x d); hires_without/with = max(0, x - F); unused = max(0, F - with); avoided = hires_without - hires_with; agency without = sum agency x d_w, with = sum agency x d_w x (1 - s_eff); avoided cost = avoided hires x loaded x counterfactual_funded_share + (agency without - agency with); net = avoided cost - run; versus_today = hires_with x loaded + (agency with - agency today) + run; payback = (build + change) / net or null.
- A: cash labour change 0 (INV-3); agency held at baseline; net = -run - (agency_scales_with_output ? implied_agency_growth : 0); implied_agency_growth = sum max(0, agency x (m_A(1 - s_eff) - 1)); agency_budget_binds per workflow = m_A > 1 / (1 - s_eff); payback null.
