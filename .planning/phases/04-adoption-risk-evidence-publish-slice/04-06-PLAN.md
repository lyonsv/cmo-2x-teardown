  <name>QA-04 cross-check</name>
  <files>scripts/crosscheck.mjs, test/crosscheck.test.js</files>
  <behavior>
    run({ html, data } = defaults) returns { failures: string[], report: { figures, chips, cites, registerRows, unreferenced, defaultsChecked } }. Checks:
    1. duplicate ids -> "duplicate id X"
    2. every data-fig (span or svg text) has a data.js entry, and its ref (claim.ref or the assumption id) is a `<tr id>` in s15 -> "data-fig X: register row R missing"
    3. every chip href and every .cite href targets an existing `<tr id="src-*|asm-*">` -> "chip/cite to #X has no register row"
    4. every `input#in-{key}` value equals toText(field, defaultValues) and every hint starts with the formatted default; every static `data-fig="calc-*"` text equals claims[id].display -> "default drift: X"
    5. every register row id is referenced at least once outside its own row (href="#id") or is a key of JUSTIFIED_UNREFERENCED with a non-empty reason; every JUSTIFIED_UNREFERENCED key is a real row that is in fact unreferenced (no stale entries) -> "unreferenced register row X" / "stale justification X"
    6. every source publisherType is in PUBLISHER_TYPES and equals the third td of its register row -> "src-X publisher type"
    7. McKinsey: the not-used note is present iff /mckinsey/i appears nowhere else in html and data.js -> "McKinsey note mismatch"
    8. every `.gaps li` bold lead is a key of GAP_TRACE (lead -> list of assumption ids or the literal 'no assumption: external evidence'), and every listed assumption id exists -> "untraced gap X"
    Mutation cases (each must yield a failure containing the named text): remove `<tr id="asm-backlog0-days">...</tr>`; change `value="40"` on #in-campaigns to `value="41"`; delete every href to one referenced source; blank one register publisher-type cell.
  </behavior>
  <implementation>
    Node built-ins plus imports from ../site/js/*.js only. Default html is read from ../site/index.html via new URL(import.meta.url). CLI block: when run directly, print each failure as "FAIL ..." and a one-line report summary, exit 1 on any failure. JUSTIFIED_UNREFERENCED starts empty; run the check, then add each genuinely unreferenced row with a one-sentence reason (for example a model assumption shown only in the register because the calculator does not expose it); never add a row that is referenced. If a check finds a real page defect (dead reference, drift, missing publisher type), fix the page or data, not the check, and list the fix in the SUMMARY.
  </implementation>
</feature>
