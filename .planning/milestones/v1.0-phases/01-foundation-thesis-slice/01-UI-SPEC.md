# Phase 1 — UI Design Contract

> Visual and interaction contract for a static editorial page. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
> Source of truth for tokens: the reference page https://lyonsv.github.io/intercom-2x-teardown/ (inline `<style>` extracted 2026-10-24). Values below are copied from it except where marked **Changed**. Upstream: 01-CONTEXT.md (locked), REQUIREMENTS.md (SHELL-04, CRED-01/02, CFO-04, QA-01/02), CLAUDE.md.

## Spacing Scale

Declared values (multiples of 4). Reference uses ad-hoc px; the executor must snap to these tokens, defined as `--s-xs` … `--s-3xl` in `:root`.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Chip vertical padding, inline gaps, code padding |
| sm | 8px | Table cell vertical padding, figcaption top margin, label-to-content gaps |
| md | 16px | Paragraph bottom margin, chip horizontal padding gap, list item gap, `.sec-head` row gap |
| lg | 24px | Callout margins, `.sec-head` bottom margin, legend padding, grid column gap in `.meta`/`.inv` |
| xl | 32px | Section top padding, figure vertical margin, h3 top margin |
| 2xl | 48px | Masthead top padding, TOC bottom margin, gap between legend/TOC/answer block |
| 3xl | 64px | `.sec-head` number column width (desktop); masthead top padding on desktop |

Layout constants (not spacing tokens): `.sec-head` / `.toc a` grid columns `64px 1fr` desktop, `32px 1fr` at <=720px (**Changed** from 38px, to stay on the declared scale); column gap 16px desktop (**Changed** from 18px), 8px mobile.

Exceptions (explicit list): 1px/1.5px/2px/3px rules and borders (hairlines, table rules, callout bar) are not spacing. Touch targets: TOC rows and any link-only row must be at least 48px tall (`min-height:48px`, row padding 16px top/bottom). Grade chips that are links need a 24x24 CSS px minimum target (WCAG 2.2 target size minimum), met by 12px mono text with 4px/8px padding plus surrounding inline space.

## Typography

Exactly 4 sizes and 2 weights (400 and 600). Reference weights 650 on `strong` are **Changed** to 600.

| Role | Size | Weight | Line Height | Family / notes |
|------|------|--------|-------------|----------------|
| Body | 17px (16px at <=720px) | 400 | 1.6 | Serif. Paragraphs, lists, table cells, standfirst, h3 (h3 is Body size at 600), pull quote (italic 400) |
| Label | 12px | 600 (400 for meta values, figcaption, `.n`) | 1.6 | Mono. Kicker, `.meta`, h4, chips, flag tags, `th`, `caption`, figcaption, TOC, `.sec-num`, `code`, `.num` cells. Uppercase with letter-spacing .12em for kicker, h4, chips, th, caption; sentence case for meta, figcaption, TOC |
| Heading | 31px (25px at <=720px) | 600 | 1.15 | Serif. `h2` section titles only, letter-spacing -.01em |
| Display | `clamp(34px, 5.2vw, 58px)` | 600 | 1.05 | Serif. `h1` page title only, letter-spacing -.015em; `em` italic in muted colour |

Rules:
- Heading hierarchy: h1 (display) > h2 (heading) > h3 (body size, 600, `margin:32px 0 8px`) > h4 (label, uppercase mono).
- Prose measure: `p, ul, ol` max-width 44em. Answer-first paragraph and standfirst max-width 46em.
- Standfirst is Body size, 400, colour `--ink-2`, line-height 1.5 (**Changed**: reference 20px; dropped to keep four sizes).
- **Changed** chips: 12px (reference 9.5px) so grade text is legible and meets target-size needs. Chip letter-spacing .08em to compensate for width.
- Tables: body cells use Body size (17px; 16px on mobile) at 400, line-height 1.5; `td.num` and `th` use Label 12px mono. No other sizes exist anywhere; there are no exceptions.
- Numbers in tables and prose figures use `font-variant-numeric: tabular-nums`.

## Color

Tokens copied from the reference `:root`. Light theme only.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `--paper` `#F4F4F0` | Page background, body |
| Secondary (30%) | `--paper-2` `#EDEDE6` | Legend/grade-key panel, `code` background, TOC row hover, skeleton "coming later" note panel, COI box background |
| Text | `--ink` `#1A1C1B` | Body text, h1/h2/h3, 2px masthead rule, table header rule, callout bar |
| Text secondary | `--ink-2` `#2C2F2C` | Standfirst, pull quote (reference uses this literal) |
| Muted | `--muted` `#62665F` (about 5.2:1 on paper, passes AA) | Kicker, meta, captions, `.sec-num`, th |
| Rule | `--rule` `#D5D6CE` | Hairline borders, table row rules, figure top rule |
| Accent (10%) | `--verified` `#17554A` | See reserved list below |
| Grade: Modelled | `--inferred` `#7A5D0F` (5.6:1 on paper, 5.25:1 on paper-2; darkened from the reference #8A6A12, which was 4.30:1 on paper-2, after code review WR-08) | Modelled chip only |
| Grade: Speculative | `--low` `#7A3B34` | Speculative chip only |
| Neutral flag | `--muted` text on `--paper-2`, 1px `--rule` border, no currentColor border | Vendor-claimed / company-reported tag |
| Destructive | none | No destructive actions on this page (read-only, no forms in Phase 1) |

Grade-to-token mapping (**Changed** from the reference's verified/inferred/low semantics, per CONTEXT):
- Benchmark -> `--verified` (class `.c-b`)
- Modelled -> `--inferred` (class `.c-m`)
- Speculative -> `--low` (class `.c-s`)
- Source flag -> `.flag` (neutral, never takes a grade colour)

Accent (`--verified`) reserved for: (1) hyperlink text colour (`a`), including the grade chips' Benchmark variant, (2) Benchmark chip, (3) the "2x" bar series in the section 02 figure, (4) `:focus-visible` outline. Nothing else. Body text, headings, borders and baseline bars never use accent. `--inferred` and `--low` appear only on their chips and, in the section 02 figure, never as bar fills (the figure uses accent for 2x, `--muted` for baseline, and a 3-step neutral ramp for stacked cost components, below).

Chart palette (SVG, all declared as CSS custom properties so print can override):
- Baseline series: `--muted` `#62665F`.
- 2x series: `--verified` `#17554A`.
- Cost component stack (generation, review, rework, tooling, rights, storage), in order: `#1A1C1B`, `#3A3D38`, `#4A4E48`, `#5A5E57`, `#6C7068`, `#7C8077`, each >= 3:1 against `--paper`, separated by a 1.5px `--paper` stroke, with review, tooling and storage hatched (SVG `<pattern>`, paper-coloured diagonal lines) so neighbours differ by texture as well as shade. Changed after code review WR-09: the original light end (`#A3A69C`, `#C4C6BC`, `#DCDDD5`) was below 3:1 against paper. Never rely on fill alone; every segment is labelled in the data table.
- Chart text: Label size, fill `--ink`; gridlines `--rule`.

Contrast: all text/background pairs must be >= 4.5:1 (chips, tags and captions included); non-text graphics >= 3:1. Grades are never conveyed by colour alone: the chip always carries the words Benchmark / Modelled / Speculative.

Focus: `a:focus-visible, summary:focus-visible { outline: 2px solid var(--verified); outline-offset: 2px; }`. Never `outline:none` without a replacement.

## Page Structure & Component Contract

Order of the page (single column inside `.wrap`):

1. **Skip link** (`<a class="skip" href="#answer">Skip to the summary</a>`), visually hidden until focused.
2. **Masthead** (`<header class="masthead">`): kicker (Label, uppercase) "A forward-looking teardown · projection, not retrospective"; `h1` "CMO 2x: what doubling a marketing organisation's output would take" with the "2x" or the clause after the colon in `<em>` (muted italic); standfirst one sentence; byline "Vincent Lyons"; bottom border 2px `--ink`.
3. **`.meta` grid** (`repeat(auto-fit,minmax(208px,1fr))`, gap 4px 24px, top border 1px `--rule`, padding-top 16px): Date (2026-10-24), Evidence base, and the four subject-org assumptions (~$1B revenue; ~$78M marketing budget, 7.8% of revenue; ~120 marketing FTE; ~40 campaigns/yr), each value followed by a Modelled chip linking to `#asm-…`. Labels in `<b>`.
4. **COI box** (`.callout.coi`, bg `--paper-2`, 3px `--ink` left bar), label "Conflict of interest", copy from CONTEXT verbatim. The same component (class `.callout.coi`, shortened label "COI note") is reused in Phase 2 next to imagery sourcing and Getty v Stability.
5. **Answer-first block** (`<section id="answer" class="answer">`, no number): <=120 words in Body size at max-width 46em, stating claim, condition (governed review), falsifier. First sentence in 600 weight. Contains `data-fig` tagged numbers with chips.
6. **Grade key / legend** (`.legend`, bg `--paper-2`, 1px `--rule` border, padding 24px): `<dl>` with three rows (chip + definition for Benchmark, Modelled, Speculative) and a fourth row for the source flag (neutral tag + "flags who said it; never upgrades a grade"). Includes the "what 2x does not mean" statement as a `.callout` directly after or inside the legend block, and the falsifier statement as a second `.callout` labelled "Falsifier".
7. **TOC** (`<nav class="toc" aria-label="Sections">`): 15 rows, each `<a href="#sNN"><span class="n">NN</span><span>Title</span></a>`. Mono Label size, rows 48px min-height, hover bg `--paper-2`. Current-section highlight is not required in Phase 1 (no JS). Sticky behaviour is not required; do not add.
8. **Sections s01 to s15** as `<section id="sNN" aria-labelledby="sNN-h">` with `.sec-head`.

Section pattern (fixed snippet, grep-checkable):
```html
<section id="s02" aria-labelledby="s02-h">
  <div class="sec-head"><span class="sec-num">02</span><h2 id="s02-h">Title</h2></div>
  ...
</section>
```
- `section{ scroll-margin-top: 16px }`, `html{ scroll-behavior: smooth }` wrapped in `@media (prefers-reduced-motion: no-preference)`.
- Section top border 1px `--rule`, top padding 32px, first section no border.

## Section 02 Figure (CFO-04) Contract

Inline `<svg role="img" aria-labelledby="f2-t f2-d" viewBox="0 0 960 H" width="100%">` with `<title id="f2-t">` and `<desc id="f2-d">`, text selectable, no external fonts (SVG text uses the mono stack at 12px equivalent in viewBox units, scaled by `width:100%`).

- Three paired horizontal-bar groups stacked vertically, 48px between groups: (1) Output per head (approved-live asset-variants per head per quarter), (2) Cost per approved-live asset, stacked by the six cost components, (3) AI spend.
- Within each group two bars: Baseline (`--muted`, top) and 2x (`--verified`, bottom), 24px bar height, 8px gap. Group label above each group, left aligned. Value labels at the bar end in text (e.g. "2.0x"), never inside low-contrast fills.
- Each bar group scaled to its own max with a stated unit; a visible note "Each panel has its own scale" in the caption. Zero baseline at x=0, no truncated axes.
- Legend row under group 2 for the six cost components (swatch 12x12 plus label).
- Every number in the figure comes from `data.js` and is mirrored in the visible table; the table carries grade chips for each row (Modelled expected).
- Mobile: SVG scales with width; minimum rendered text must stay >=10px, so at <=480px the viewBox width is 640 via a CSS-only `min-width:560px` inside a scroll wrapper (`.table-scroll` pattern, focusable region). Do not shrink below that.
- Print: bars switch to patterns/greys that remain distinguishable in black and white (baseline light grey, 2x solid black, stack in the greyscale ramp already declared).

## Interaction & State Contract

The Phase 1 page loads no script at all (it must work fully with JS off). `data.js` and `calc.js` are ES modules used by the `node:test` tests only in Phase 1 (and by the calculator UI in Phase 3). Interactions are native only.

| Interaction | Contract |
|-------------|----------|
| Anchor navigation | TOC links and chip links jump with smooth scroll when motion is allowed; `:target` row highlight on register rows; focus moves with the hash natively (no `tabindex="-1"` is needed on sections or register rows; the `:target` highlight is sufficient) |
| Hover | Links underline thickness .06em to .12em; TOC rows bg `--paper-2`; chips underline. No transitions longer than 120ms; none under `prefers-reduced-motion` |
| Focus | Visible 2px `--verified` outline offset 2px on every link, chip link, summary, and scroll region |
| Scroll regions | Every table wider than its container sits in `.table-scroll` with `tabindex="0"`, `role="region"`, accessible name |
| Loading / empty / error | Not applicable (static content). Skeleton sections use the `.later` note. A missing register entry is a test failure, not a UI state |
| Reflow | Usable at 320 CSS px with no two-dimensional page scroll; only table scroll regions scroll horizontally |

## Responsive & Print Contract

- Breakpoint: single breakpoint at `max-width:720px` (as reference): body 16px, `.wrap` padding 16px, sec-head/claim/toc grids `32px 1fr` with 8px gap, h2 25px.
- At <=480px `.meta` becomes one column; `.metric-trio` one column.
- `@media print` (CFO print/PDF): `body{background:#fff;color:#000;font-size:10.5pt}`; `.toc` and `.skip` hidden (**same as reference**), but keep the grade key visible; `a{color:#000}`; register URLs print once because their link text is the full URL (the `::after` href rule was dropped after code review IN-05, as it printed each URL twice); `figure, table, .callout, .legend, tr{break-inside:avoid}`; `section{break-inside:auto}`; chips keep their 1px border and text so grades survive in B&W; remove `.later` bg; `.table-scroll{overflow:visible}`; hairlines `#ccc`; `h2{break-after:avoid}`.

## Accessibility Contract (WCAG 2.2 AA, QA-01 foundation)

- Language `<html lang="en-GB">`; `<meta name="viewport" content="width=device-width, initial-scale=1">`; `<title>` matches h1.
- One `<h1>`; h2 per section; no skipped levels. Landmarks: `<header>`, `<nav aria-label="Sections">`, `<main id="main">`, `<footer>`.
- Grades: text word always present; chip link accessible name is the visible text plus context via `aria-label` only if the visible text alone is ambiguous (e.g. `aria-label="Modelled, see assumption asm-gartner-share"`). Do not make the aria-label contradict the visible text.
- Tables: `<caption>`, `<th scope="col|row">`, no layout tables.
- SVG: `role="img"`, `<title>`, `<desc>`, plus the visible table equivalent.
- Colour contrast and focus as in the Color section. No content conveyed by colour only.
- Respect `prefers-reduced-motion`.

## Copywriting Contract

Voice: British English, analytical and sceptical, like the reference. No exclamation marks, no marketing superlatives. Numbers carry a chip.

| Element | Copy |
|---------|------|
| Primary CTA | None. The page is read-only in Phase 1. The primary navigational action is the TOC; skip link text: "Skip to the summary". (Phase 3 CTA will be "Run your own numbers".) |
| Kicker | A forward-looking teardown · projection, not retrospective |
| Title (h1) | CMO 2x: what doubling a marketing organisation's output would take |
| COI box | Label "Conflict of interest". Body: "The author works at iStock/Getty Images. The page is vendor-neutral by design; where imagery sourcing or Getty v Stability is discussed, this note is repeated." |
| Grade key labels | Benchmark: "Published by a primary or otherwise checkable source, and the figure matches it." Modelled: "Derived by this page from stated assumptions; change the assumption and the number changes." Speculative: "A judgement with no checkable source; shown so you can discount it." Flag: "vendor-claimed / company-reported: says who made the claim. It never raises a grade." |
| What 2x does not mean | Heading "What 2x does not mean". Body: "It does not mean twice as many assets generated, twice the budget, or half the team. It means twice as many approved-and-live asset-variants per marketing head per quarter, at flat budget, with outcomes that hold." |
| Falsifier | Label "Falsifier". Body (locked): "If approved-live variants per head double but holdout-measured conversion/CAC does not improve and first-pass compliance falls within 2–3 quarters, the 2x claim is false for that org." |
| AI spend framing (s02) | "AI spend is a floor, not a target. Teams that are rewarded for spending on AI will spend on AI (Goodhart's law); the measure that matters is the cost of an approved, live asset." |
| Skeleton note | "Coming in a later update." plus one-sentence scope per section |
| Empty state heading | Not applicable (no data-driven UI in Phase 1). Skeleton sections are the only "empty" content: see "Skeleton note" |
| Empty state body | "Coming in a later update." followed by the scope sentence, e.g. "This section will show how localisation doubles output without doubling review." |
| Error state | Not applicable (no inputs). No script is loaded, so there is no JS failure state. Dead anchor = test failure |
| Gartner caveat (if not confirmed) | "Secondary source: the Gartner 7.8% figure is reported by trade press; we could not confirm the primary release." (shown only when graded Modelled per CONTEXT) |
| Destructive confirmation | None: no destructive actions exist on the page |

Section titles for the 15 TOC rows: use the research structure; s01 "Claim & measurement", s02 "The CFO answer", s12 "How this compares", s15 "Source register". Titles for 03-11, 13, 14 are the executor's to take from `.planning/research/SUMMARY.md`; they must be final-quality (not "TBD") because the TOC is public.
