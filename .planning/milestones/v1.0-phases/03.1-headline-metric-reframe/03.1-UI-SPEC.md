## Copywriting rules

- Use "campaign-markets" consistently. Define it once in s01: one campaign live in one market. In prose outside s01 use "campaigns live across markets".
- Use "Brief-to-live", never "cycle time", in reader-facing copy.
- Never pair "per marketing head" with variants in a claim.
- British English. No numerals outside data-figs (numeric gate unchanged).
