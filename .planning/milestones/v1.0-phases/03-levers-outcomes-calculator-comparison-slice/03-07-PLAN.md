## Phase Goal

**As a** CMO (or their CFO) reading the page, **I want to** see the five other levers and the outcome case, run my own numbers through the calculator, and see fairly how the approach compares with named vendors, **so that** I can judge whether a 2x programme is credible for my organisation and improves outcomes rather than only volume.

<objective>
Add headcount scenarios (redeploy / hold / reduce with change-management cost) and the sensitivity table, both pure and tested, both static by default and live with JavaScript.

Purpose: the CFO's questions are "what happens to headcount" and "which assumption carries the result"; these answer them with the reader's numbers.
Output: model functions, two new assumptions, a radio group, two tables, live wiring, extended smoke check.
</objective>
