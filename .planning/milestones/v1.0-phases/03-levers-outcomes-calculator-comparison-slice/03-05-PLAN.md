## Phase Goal

**As a** CMO (or their CFO) reading the page, **I want to** see the five other levers and the outcome case, run my own numbers through the calculator, and see fairly how the approach compares with named vendors, **so that** I can judge whether a 2x programme is credible for my organisation and improves outcomes rather than only volume.

<objective>
Build the pure calculator core (fields registry, model, presenter, weakest-grade logic) and render the default scenario statically in s11, so a reader without JavaScript already sees the full results table with grades, break-even and capacity floor.

Purpose: this is the testable spine every later calculator plan extends; the static table is the no-JS deliverable and the drift baseline for the live tool.
Output: format.js, fields.js, model.js, generated calc claims in data.js, s11 static results, tests.
</objective>

Summary: "At 2x, your team approves {x} variants per head per quarter at {y} per approved asset, with reviewers at {z} of capacity." or "...with reviewers over capacity at {z} of capacity." No output string ever contains NaN, Infinity, undefined or null.
